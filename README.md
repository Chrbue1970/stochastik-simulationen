# Stochastik-Simulationen BG 13

Zehn interaktive Simulationen zu den Arbeitsheften „Zufallsexperimente und Wahrscheinlichkeiten“ und „Binomial- und Normalverteilung“ (Berufliches Gymnasium, Klasse 13).

Jede Simulation ist eine einzelne HTML-Datei ohne Anmeldung und ohne Datenspeicherung. `index.html` ist die Startseite mit allen zehn Simulationen.
